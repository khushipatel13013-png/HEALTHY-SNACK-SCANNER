# Healthy Snack Scanner

An AI-powered web application that analyzes food images and provides estimated nutritional information using Google's Gemini AI model.

## Features

* Upload food images
* Detects whether the image contains food
* Estimates calories, protein, carbohydrates, fat, fiber, and sugar
* Provides a health rating (Healthy, Moderate, Unhealthy)
* Modern and responsive user interface
* Built with Flask and Gemini API

## Technologies Used

* Python
* Flask
* HTML, CSS, JavaScript
* Google Gemini API

## How to Run

1. Clone the repository
2. Create a `.env` file and add your Gemini API key
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```
4. Run:

   ```bash
   python app.py
   ```
5. Open `http://127.0.0.1:5000`

## Project Objective

To help users quickly understand the nutritional content of food items through AI-powered image analysis.
